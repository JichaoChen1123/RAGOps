# RAGOps 用户故事与验收标准

## 1. 优先级说明

| 优先级 | 含义 |
| --- | --- |
| P0 | MVP 上线和端到端闭环必需；缺失则不能验收 |
| P1 | MVP 后首批增强；不阻断离线评测闭环 |
| P2 | 中长期能力；需在真实使用数据基础上再设计 |

本文件以可独立验收的用户故事描述需求。统一业务边界、对象定义与非功能要求见 [PRD](./prd.md)。

## 2. 故事地图

| 用户活动 | 准备资产 | 发起评测 | 分析结果 | 定位故障 | 决策发布 |
| --- | --- | --- | --- | --- | --- |
| P0 主路径 | 创建项目、导入数据集、保存配置快照 | 预检、提交、查看进度、取消/重试 | 查看指标、筛选、样本下钻 | 查看疑似原因与证据、反馈 | 正式成对对比、门禁结论 |
| P1 增强 | 协作标注、自定义指标 | 定时/CI 触发、生产 Trace 抽样 | 趋势、分享与导出 | 诊断基准集与批量复核 | 多版本矩阵、显著性检验 |
| P2 演进 | 主动学习采样 | 在线持续评测 | 跨项目基准 | 辅助修复建议 | 自动化发布策略 |

## 3. P0 用户故事

### US-01 创建项目

**作为** AI 应用负责人，**我希望** 创建独立项目并指定成员角色，**以便** 将评测数据、配置和报告限制在正确团队内。

- **输入**：项目名称、说明、负责人、成员角色。
- **操作**：创建项目、邀请/移除成员、修改角色。
- **输出**：项目主页、成员列表、审计记录。

**验收标准**

- [ ] 项目名称为空时不可提交，并显示字段级错误。
- [ ] 创建成功后当前用户为项目负责人，并可进入数据集导入入口。
- [ ] 只读者不能执行任何写操作；后端也返回权限拒绝，而非只隐藏按钮。
- [ ] 成员或角色变化记录操作者、时间、对象和结果。

### US-02 保存应用配置快照

**作为** RAG 开发者，**我希望** 保存一次可追溯的应用配置，**以便** 评测结果能对应到 Prompt、模型与检索版本。

- **输入**：评测目标、Prompt 版本、生成模型、Embedding、Rerank、Top K、知识库/索引版本及可选说明。
- **操作**：检查目标连通性、保存快照、比较快照字段。
- **输出**：不可变快照 ID、掩码摘要、检查结果。

**验收标准**

- [ ] 快照保存后获得唯一 ID，列表展示创建人和时间。
- [ ] 已用于运行的快照不可覆盖；修改后产生新 ID。
- [ ] 未上报字段显示“未知”，不得由平台推断。
- [ ] 凭据在页面、报告、日志和审计正文中均不显示明文。
- [ ] 连通性检查能区分认证、超时、契约不兼容和目标应用错误。

### US-03 导入评测数据集

**作为** 企业知识库负责人，**我希望** 从 CSV 或 JSONL 导入评测样本，**以便** 团队复用一套受版本控制的测试集。

- **输入**：UTF-8 CSV/JSONL、数据集名称、版本说明。
- **操作**：上传、映射字段、预览、校验、确认。
- **输出**：数据集版本、字段覆盖率、警告与错误文件。

**验收标准**

- [ ] question 缺失、文件不可解析或超过容量上限时阻止导入。
- [ ] 确认前展示前 20 条映射结果、总样本数和字段覆盖率。
- [ ] 错误信息包含行号、字段、原因和建议动作，并可下载。
- [ ] 结构性错误存在时不创建部分版本。
- [ ] 缺少参考答案/参考文档只产生指标可用性警告，不误报为 0 分。
- [ ] 成功版本包含唯一 ID、文件摘要、样本数、映射、创建人和时间。

### US-04 选择可用指标

**作为** 评测任务创建者，**我希望** 在提交前知道每项指标所需的数据，**以便** 避免任务完成后才发现无法计算。

- **输入**：数据集版本、应用配置快照、候选指标。
- **操作**：运行兼容性预检、移除不兼容指标或补充资产。
- **输出**：可用、不可用、存在风险的指标清单及原因。

**验收标准**

- [ ] 每项指标列出所需字段和实际覆盖情况。
- [ ] 缺少必需输入的指标不可被带入正式任务。
- [ ] 可选字段覆盖不完整时展示预计有效样本数。
- [ ] 0 分、缺输入、不适用、评测器错误在产品语义上彼此独立。

### US-05 创建离线评测任务

**作为** AI 应用开发者，**我希望** 对固定数据集和配置运行评测，**以便** 获得可复现结果。

- **输入**：数据集版本、应用配置快照、指标配置。
- **操作**：预检、确认样本数和预计消耗、提交。
- **输出**：任务 ID、运行 ID、状态和进度。

**验收标准**

- [ ] 缺少任一版本选择时不可提交。
- [ ] 提交后 2 秒内返回任务 ID，重复提交有明确去重/确认机制。
- [ ] 运行记录固化三个输入版本，之后的资产编辑不改变本次运行。
- [ ] 页面刷新或重新登录后仍能找到任务和当前进度。
- [ ] 样本结果能关联 request_id 与 sample_id。

### US-06 查看、取消和重试任务

**作为** 模型应用后端工程师，**我希望** 查看长任务进度并处理失败，**以便** 控制消耗且不丢失已完成结果。

- **输入**：运行中的任务或包含失败样本的运行。
- **操作**：查看状态、取消、选择失败样本重试。
- **输出**：状态时间线、错误分布、新重试尝试。

**验收标准**

- [ ] 状态至少包含 queued、running、partially_completed、completed、failed、cancelled。
- [ ] 进度同时展示完成、成功、失败和总样本数。
- [ ] 取消后不再发起新请求，已完成结果继续可见。
- [ ] 单样本失败不会删除其他样本结果。
- [ ] 重试创建新尝试并关联原运行，原结果保持不变。

### US-07 查看评测总览

**作为** RAG 系统维护者，**我希望** 在一个报告中查看检索、生成、引用和工程指标，**以便** 判断问题集中在哪个阶段。

- **输入**：已完成或部分完成的运行。
- **操作**：查看指标卡、分布、失败构成和标签切片。
- **输出**：聚合报告及版本追溯信息。

**验收标准**

- [ ] 报告头部展示数据集、应用配置、指标配置和运行标识。
- [ ] 每项指标展示有效样本数、排除数及排除原因入口。
- [ ] 部分完成报告显著提示缺失样本，不将其计为 0 分。
- [ ] 检索、生成、引用和工程指标在视觉上可区分但使用一致的分数方向说明。
- [ ] 10,000 条规模下报告首屏 P95 满足 PRD 性能要求。

### US-08 按标签和失败条件筛选

**作为** 企业知识库负责人，**我希望** 按知识域、问题类型和失败条件切片，**以便** 识别被总体均分掩盖的长尾问题。

- **输入**：报告、标签、指标范围、失败类型、执行状态。
- **操作**：组合筛选、排序、清除条件。
- **输出**：匹配样本数、切片指标和样本列表。

**验收标准**

- [ ] 标签多选与其他条件可组合。
- [ ] 筛选后的指标分母与样本列表数量一致。
- [ ] 页面返回后保留筛选、排序和分页上下文。
- [ ] 空结果说明当前条件，并提供一键清除筛选。

### US-09 下钻样本证据

**作为** RAG 开发者，**我希望** 从任一低分指标进入具体样本，**以便** 核对问题、答案、引用和检索上下文。

- **输入**：指标卡、分布区间或失败类型。
- **操作**：打开样本列表和详情。
- **输出**：原始输入输出、评分理由、证据与运行错误。

**验收标准**

- [ ] 从聚合指标最多两次操作到达对应样本列表。
- [ ] 样本详情展示问题、期望答案、实际答案、引用、检索上下文及其 rank。
- [ ] 引用能定位到支持它的上下文；无法关联时明确提示。
- [ ] 自动评审结果展示评审器、规则版本和理由。
- [ ] 敏感字段按项目规则脱敏，且用户知道内容已被脱敏。

### US-10 查看失败诊断

**作为** RAG 系统维护者，**我希望** 看到失败样本的疑似阶段、原因与证据，**以便** 决定先排查检索还是生成。

- **输入**：样本结果、阶段指标、检索上下文、引用、参考字段和错误。
- **操作**：查看诊断、切换并列原因、跳到证据。
- **输出**：疑似阶段、失败分类、证据、置信度或不可判定说明。

**验收标准**

- [ ] 诊断覆盖 PRD 定义的初始失败分类。
- [ ] 每个非“不可判定”结论至少关联一项用户可见证据。
- [ ] 同一样本支持多个并列疑似原因。
- [ ] 缺少检索结果时不得给出确定性的检索根因。
- [ ] 规则或评审器异常显示为“评测器错误”，不归咎于目标应用。

### US-11 反馈诊断准确性

**作为** 诊断结果使用者，**我希望** 标记诊断是否准确并补充备注，**以便** 团队积累可复核的诊断基准。

- **输入**：一条诊断、准确/不准确选择、可选备注。
- **操作**：提交或更新自己的反馈。
- **输出**：反馈状态、操作者、时间和审计记录。

**验收标准**

- [ ] 准确性选项必选，备注可选。
- [ ] 提交后立即回显，且不修改历史原始诊断内容。
- [ ] 只读者不可提交反馈。
- [ ] 用户可查看自己最新反馈，负责人可查看聚合反馈。

### US-12 创建正式版本对比

**作为** 发布负责人，**我希望** 比较基线和候选运行，**以便** 判断 Prompt、模型、Embedding 或 Rerank 改动的影响。

- **输入**：基线运行、候选运行。
- **操作**：兼容性检查、确认正式或探索性对比。
- **输出**：配置差异、指标差值、配对样本统计。

**验收标准**

- [ ] 正式对比要求同一数据集版本、样本集合和指标配置。
- [ ] 不兼容运行只允许带警告的探索性对比，不输出正式门禁结论。
- [ ] 差值按 sample_id 成对计算并显示有效配对样本数。
- [ ] 配置差异覆盖 Prompt、模型、Embedding、Rerank、Top K、知识库/索引版本。
- [ ] 未上报的配置项显示“未知”，不得假设两边相同。

### US-13 下钻改善与回退样本

**作为** AI 应用开发者，**我希望** 查看候选版本改善或回退的具体样本，**以便** 理解平均分变化背后的原因。

- **输入**：一个版本对比。
- **操作**：切换改善、回退、不变、新增错误；按标签筛选。
- **输出**：样本级前后分数、答案和证据差异。

**验收标准**

- [ ] 可一键查看“基线通过、候选失败”的样本。
- [ ] 每行展示基线值、候选值、差值方向和失败类型变化。
- [ ] 样本详情可并排查看前后答案、引用和检索上下文。
- [ ] 总体改善但关键标签回退时，切片风险在首屏可见。

### US-14 获得可复算的门禁结论

**作为** 发布负责人，**我希望** 按关键指标阈值得到通过、不通过或无法判断，**以便** 形成一致的发布决策。

- **输入**：正式对比、指标阈值、最大允许回退样本比例。
- **操作**：计算门禁、展开触发规则。
- **输出**：结论、规则实际值、失败/缺失原因。

**验收标准**

- [ ] 结论只包含通过、不通过、无法判断三种。
- [ ] 每条规则展示指标、方向、阈值、实际值、有效样本数。
- [ ] 任一关键规则不可计算时整体不得默认为通过。
- [ ] 相同输入重复计算得到一致结果。
- [ ] 门禁结论是建议，不自动修改或发布目标应用配置。

### US-15 查询审计与追溯信息

**作为** 项目负责人，**我希望** 查询关键变更和每份报告的来源版本，**以便** 复盘异常并满足治理要求。

- **输入**：对象、操作者、动作、时间范围。
- **操作**：筛选审计事件、打开关联对象。
- **输出**：事件列表和不可变版本引用。

**验收标准**

- [ ] 数据集创建、配置变更、任务创建/取消、权限变更和诊断反馈均有记录。
- [ ] 事件包含操作者、时间、对象、动作和结果。
- [ ] 审计正文不包含凭据和被规则禁止的敏感文本。
- [ ] 从报告可直接查看其四类版本信息，追溯率为 100%。

## 7. 需求就绪条件

任一 P0 故事进入交付前，需满足：

- 输入、输出、权限主体和错误状态已明确。
- 所依赖的数据字段有样例，缺失时的产品行为已定义。
- 设计稿覆盖正常、空、加载、部分成功、失败和无权限状态。
- 算法指标给出版本标识、分数方向、有效输入和不可计算条件。
- 后端接口支持稳定对象 ID、幂等语义、分页/筛选和关联 ID。
- 验收数据包含至少一个成功样本、一个业务失败样本和一个系统错误样本。

## 8. 尚待决策

以下问题会影响多个故事，应在 P0 开发排期前确认：

1. 首个评测对象接入方式与请求/响应样例。
2. 首批试点的数据规模、运行并发和成本预算。
3. 关键业务指标、阈值以及高风险标签。
4. 外部模型评审器可处理的数据边界。
5. 权威参考文档 ID 规则与引用定位粒度。
6. 默认数据保留期、删除恢复窗口和脱敏字段。
7. 正式门禁是否需要人工审批状态；MVP 默认只输出建议。
8. 诊断反馈的复核责任人与复核频率。
