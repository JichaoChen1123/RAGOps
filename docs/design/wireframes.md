# RAGOps 核心页面线框

> 状态：低保真桌面端线框，尚未实现。用于对齐布局、信息层级和交互，不规定最终视觉品牌。基准画布宽度为 1440px，左侧导航 216px，内容区最小宽度 1024px。

## 1. 通用工作台框架

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ RAGOps  [项目：客服知识库 v]      [全局搜索 /]       任务(2)  帮助  用户   │
├──────────────┬──────────────────────────────────────────────────────────────┤
│ 项目概览     │ 面包屑 / 页面标题                     [次要操作] [主要操作] │
│ 数据集       ├──────────────────────────────────────────────────────────────┤
│ 评测任务     │ 状态/版本/更新时间                                               │
│ 版本对比     │                                                              │
│ 趋势看板     │ 页面内容                                                     │
│              │                                                              │
│              │                                                              │
│ 项目设置     │                                                              │
└──────────────┴──────────────────────────────────────────────────────────────┘
```

交互约定：

- 页面主要操作固定在标题区右侧；每页最多一个强调色主按钮。
- 筛选条在滚动时吸顶；已应用筛选以标签显示，并提供“清除全部”。
- 右侧检查器宽 360–480px，用于上下文编辑；重要证据不只放在检查器内。
- 表格首列和操作列可固定；危险操作进入二次确认并展示影响对象。
- 所有图表提供“查看数据表”和“下载当前数据”入口。

## 10. 响应式与密度

- `>= 1280px`：完整侧栏、双列/三列看板、诊断双栏。
- `1024–1279px`：侧栏收窄为图标，指标卡横向滚动，右侧复核区改为抽屉。
- `< 1024px`：保留只读报告和样本证据的单列模式；创建任务、字段映射和复杂对比提示使用桌面端。
- 表格默认紧凑行高，并提供紧凑/舒适密度切换；用户偏好本地保存。

## 11. 原型验证清单

- 首次进入项目后，用户能在 10 秒内找到最新门禁失败原因和对应运行。
- 从任一失败聚合进入具体样本不超过两次点击。
- 样本页无需切换路由即可看清检索文档、实际上下文、答案与引用证据。
- 版本对比能清晰解释比较是否成立，以及差值方向是 `B - A`。
- 图表筛选、表格结果、URL 和导出范围始终一致。
- 未配置、无数据、计算中、计算失败、权限不足与真实 0 值均有不同表达。
