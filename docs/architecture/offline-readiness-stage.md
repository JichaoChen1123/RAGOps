本阶段目标是在没有真实凭据和真实数据的情况下，让项目可启动、可导入人工构造样本、可执行模拟任务并持久化查看报告，为后续真实模型和真实数据接入打好基础。

## 硬边界

- 不连接真实模型服务，不登录用户账号，不消耗模型 API 或订阅额度，不读取用户已有模型凭据进行探测。
- 不下载、收集或导入真实测试数据；只用少量人工构造样本、模拟提供方及内存模拟 HTTP 传输。
- 不引入 LangGraph，不扩展向量库、模型训练、账号接入等无关范围。
- 默认禁止模型网络请求，即使环境已有凭据也不自动调用；启动、就绪检查、配置查询及 UI 刷新都不能探测提供方。
- 官方 Codex 集成仅保留扩展接口和待验证问题。本阶段不实现登录或账号接入，不把 ChatGPT Plus 当作已可用的通用 API 额度。
- 凭据只在后端处理，不进入前端构建参数、API 响应、运行快照、日志、异常消息、报告或 GitHub。
- 这些限制适用于 RAGOps 产品实现和测试；团队使用已配置的开发智能体完成此次明确委派的开发工作，不做额外模型连通性实验。
- 所有成果在独立分支和 PR 中记录；不得直接修改或合并到 main，不删除旧数据或重建数据库来代替迁移。

## 负责人必须冻结的公共契约

在 `docs/architecture/model-execution-contract.md` 定义下列契约，并附最小请求、响应、错误和报告 JSON 示例。保持现有架构，确有必要才新增抽象。

1. 提供方无关请求：问题、仅模型可见的上下文、Prompt、生成参数；不得含参考答案、gold 标签、预存回答或整份样本 metadata。
2. 提供方无关响应：本次回答、实际模型、结束原因、耗时、可选 Token 用量、可选提供方请求 ID、模拟标识；未知字段为 null，不能编造消耗或成本。
3. 统一错误：未配置、外部调用禁用、鉴权失败、限流、超时、传输失败、响应格式错误；错误码、可重试性、尝试次数和用户可见安全信息有确定语义。
4. 适配器接口和工厂：任务业务与具体传输分离；鉴权由适配器处理，通用接口不能要求每个提供方都具备 API Key/Base URL。
5. 配置与状态：前端 mock/api、后端执行器、提供方未配置/已配置未验证/真实已验证彼此独立。模拟 HTTP 成功不能标记真实已验证；配置变化后不能沿用旧验证状态。
6. 执行与运行快照：创建时固定执行方式、Prompt/生成配置、数据版本；不得保存凭据。每个样本保留本次输出、错误、元数据、时间和必要尝试记录，评测只能读本次结果。
7. 数据版本：分开原始问题、参考标签、给定/实际检索上下文、历史预存回答、本次输出、评测结果；保留来源、文档/片段 ID、数据版本和上下文来源。
8. 指标状态：执行成功率不等于答案质量；给定/未知来源上下文不能算实际检索召回；引用可解析不等于语义支持；未实现语义判断不出分数。旧记录保持 legacy/unknown，不能倒推本次模型身份或真实连接。
9. API 字段与兼容：任务、样本、运行记录、配置状态、报告和导出字段一致；缺失值、导入行/字段错误、未知版本有明确处理；旧客户端和旧库处理方式写清楚。

## 实现要求

### 模型层、配置与执行

- 完成模拟适配器；其回答来自明确的模拟逻辑/模拟响应，不从评测标签或数据集预存回答生成。
- 完整实现 OpenAI 兼容适配器的请求组装、响应解析和错误映射，可注入内存模拟 HTTP 传输验证。不得在测试中使用真实提供方 URL 发请求。
- 模型真实外部调用开关默认关闭；任何网络路径都先检查开关，包括重试和连接检查。离线传输注入只用于明确的测试路径，不能作为用户输入绕过禁用。
- 重试和超时都有硬上限，明确总尝试次数。鉴权和格式错误不无谓重试；限流退避及 Retry-After 不能无限等待；超时有单次与总时间边界。
- 缺配置时应用与模拟执行仍可启动；请求不可用的执行方式返回明确原因，不静默转成模拟执行，不因为已有 Key 自动选真实适配器。
- 正确维护任务创建、运行、部分失败、全部失败、结果保存与报告查询的状态。失败也要可查错误和已保存运行记录，避免永远 running。
- 本次输出先保存并用于评测；不修改原始样本和参考标签；同一数据集不同运行可得到不同回答，各自历史保留。
- `.env.example`、Compose、启动教程和后端校验相互一致。新运行依赖应进入正式依赖和锁文件，而不能仅停留在 dev 依赖。

### 数据和展示

- 统一创建与导入的字段校验、空白/null/缺失处理、重复 ID、上下文/引用关系和 schema_version；为已有 1.0 数据明确兼容策略。
- 新增字段要有保留旧数据、幂等升级、升级后可查询旧报告的迁移验证；不能只调用 `create_all` 或删除数据库。
- 前端显示数据源、后端执行模式、提供方连接状态。`VITE_API_MODE=api` 只表示连接项目后端；模拟结果、未验证状态须可识别。
- 任务执行状态、质量评估状态、具体指标分别展示；unknown/not_evaluated/not_applicable 不能被转成 0、100 或通过。
- 报告与导出展示问题、参考答案、本次回答、上下文来源、引用、错误、运行快照和已有运行记录。未知 Token、成本、未执行指标显示未知或未评估。
- 前端能连接本地真实项目后端完成构造样本创建/导入/发布、模拟任务执行、报告查看，刷新或后端重启后仍能读取数据库中的成果。
